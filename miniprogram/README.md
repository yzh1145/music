# 云音乐 · 微信小程序端

原生微信小程序，复用仓库后端（Spring Boot）的 `/api` 接口与静态资源。

## 快速导入

1. 先按根目录 README 启动后端，确认 <http://localhost:8080/api/home> 正常；
2. 微信开发者工具 → 导入项目 → 目录选择 **本文件夹（`miniprogram/`）**；
3. AppID 选择「测试号」即可；
4. 「详情 → 本地设置」勾选 **不校验合法域名**；
5. 编译运行。

后端地址默认 `http://localhost:8080`，可在小程序 **我的 → 设置** 中修改为局域网地址。

演示账号：`test / 123456`、`admin / 123456`。
